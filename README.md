# DBMS Project

A relational database management system project developed using SQL.

## Features

- Database creation scripts
- Table creation with constraints
- Sample data insertion
- Stored procedures
- Test queries
- ER Diagram
- Project documentation

## Project Structure

```
createdb.sql              # Creates the database
tables.sql                # Creates all tables
sample_data.sql           # Inserts sample records
stored_procedures.sql     # Stored procedures
test_calls.sql            # Procedure execution and testing
ER Diagram.jpg            # Database schema
DBMS_project_report.docx  # Project report
```

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## How to Run

1. Execute `createdb.sql`
2. Run `tables.sql`
3. Execute `sample_data.sql`
4. Run `stored_procedures.sql`
5. Test using `test_calls.sql`
